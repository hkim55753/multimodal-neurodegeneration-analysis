# Methods Overview

This project proposes computational and neuroimaging-informed analyses examining neuropsychiatric manifestations associated with alcohol-related neurodegeneration and Parkinsonian syndromes.

Potential analyses include cerebellar volumetric assessment, exploratory clinical-imaging correlation analyses, and computational phenotyping approaches utilizing publicly available neuroimaging datasets where applicable.

Variables of interest include cognitive impairment, mood symptoms, gait dysfunction, psychiatric symptom burden, and markers of cerebellar pathology. Statistical approaches may include multivariate regression modeling, dimensional reduction techniques, and exploratory clustering analyses aimed at identifying clinically relevant neuropsychiatric patterns across overlapping neurodegenerative syndromes.
